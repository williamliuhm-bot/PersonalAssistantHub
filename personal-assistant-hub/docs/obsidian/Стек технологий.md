# Стек технологий

## Frontend — [[Frontend]]
- React 18, TypeScript, Vite 5
- MUI 5 + Emotion, Framer Motion, Recharts
- `@hello-pangea/dnd` (Kanban), dayjs, axios, xlsx
- Electron 29 + electron-builder
- Vitest + Testing Library
- i18n: `ru` / `en`
- Тема: light / dark / system (Plus Jakarta Sans, SoftCard)

## Backend
- Python 3.12+, FastAPI, Uvicorn, Pydantic v2
- SQLAlchemy 2 async + asyncpg
- PyJWT, bcrypt
- Celery 5 + Redis
- httpx (межсервисные вызовы)
- scipy / numpy ([[Integration Service]])
- python-telegram-bot, aiosmtplib, Jinja2 ([[Notification Service]])
- slowapi (rate limit в [[API Gateway]])

- Redis 7 Alpine
