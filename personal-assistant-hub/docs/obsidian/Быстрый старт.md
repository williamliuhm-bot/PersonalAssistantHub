# Быстрый старт

## Требования
- Docker + Docker Compose
- Node.js 18+ (фронт локально)
- Python 3.12+ (бэкенд локально)

## Docker (рекомендуется)

```bash
cd personal-assistant-hub
cp .env.example .env
docker-compose up -d
docker-compose exec integration-service python scripts/seed_data.py
```

| Сервис | URL |
|--------|-----|
| Frontend | http://localhost:5173 |
| Gateway Swagger | http://localhost:8000/docs |
| Auth … Integration | `:8001` … `:8005` /docs |

Демо: `demo@example.com` / `password123`

## Фронт локально

```bash
cd frontend
npm install
npm run dev          # Vite
npm run electron:dev # Electron + Vite
```

## Бэкенд локально (пример Auth)

```bash
cd auth-service
python -m venv venv
# Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8001
```

## Тесты

```bash
pip install -r tests/requirements-test.txt
pytest tests/ -v
```
