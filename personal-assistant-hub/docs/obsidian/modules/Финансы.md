## Счета
Типы: Cash, Bank, Card, Savings. Мультивалютность.

```python
class AccountType(str, enum.Enum):
    CASH = "CASH"
    BANK = "BANK"
    CARD = "CARD"
    SAVINGS = "SAVINGS"
```

## Категории / транзакции / бюджеты

```python
class TransactionType(str, enum.Enum):
    INCOME = "INCOME"
    EXPENSE = "EXPENSE"
    TRANSFER = "TRANSFER"

class BudgetPeriod(str, enum.Enum):
    WEEKLY = "WEEKLY"
    MONTHLY = "MONTHLY"
    YEARLY = "YEARLY"
```

Recurring: `is_recurring` + `recurring_day` → событие в [[Integration Service]] → задача «Pay …».
