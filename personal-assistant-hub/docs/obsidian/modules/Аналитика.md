## Celery Beat

```python
# integration-service/app/celery_beat.py
celery_app.conf.beat_schedule = {
    "analyze-productivity-daily": {
        "task": "app.tasks.analyze_productivity",
        "schedule": crontab(hour=23, minute=0),
    },
    "forecast-budget-daily": {
        "task": "app.tasks.forecast_budget",
        "schedule": crontab(hour=6, minute=0),
    },
}
```

## Event bus

```python
@app.post("/api/events")
async def receive_event(event: EventPayload, request: Request):
    if event.event_type == "recurring_payment_created":
        auto_create_task_from_payment.delay(event.model_dump())
```

API: `/api/analytics/productivity-reports`, `/api/analytics/budget-forecasts` (+ i18n insights).
