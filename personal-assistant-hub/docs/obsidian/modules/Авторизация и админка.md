# Авторизация и админка

Сервис: [[Auth Service]] · gateway JWT.

![[assets/ui-login.png]]

## Клиентский поток

```tsx
// frontend/src/pages/Login.tsx
const handleLogin = async () => {
  await login({ email: username, password });
  navigate(getStartScreenPath(settings.startScreen), { replace: true });
};
```

## Роутинг

```tsx
// frontend/src/App.tsx
<Route path="/login" element={<Login />} />
<Route path="/tg" element={<TelegramMiniApp />} />
<Route path="/" element={<ProtectedRoute><Layout /></ProtectedRoute>}>
  <Route path="dashboard" element={<Dashboard />} />
  {/* finance, tasks, calendar, habits, analytics, notifications, settings */}
  <Route path="admin/users" element={<AdminRoute><AdminUsers /></AdminRoute>} />
</Route>
```

## Роли
- `user` — обычный доступ
- `admin` — `/admin/users`
- Bootstrap: `ADMIN_EMAIL` → admin при старте Auth

Logout → blacklist JWT в Redis до expiry.
