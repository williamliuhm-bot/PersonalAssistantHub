# Уведомления

Сервис: [[Notification Service]] · UI: `/notifications`.

## Каналы
Email (SMTP), Telegram, Push — асинхронно через Celery worker `notification-celery-worker`.

## In-app
Список, mark read / mark all, delete, send.

## Предпочтения
В [[Настройки]] (localStorage): per-module push/email, quiet hours.

Связь с ботом: [[Telegram]].
