# Настройки

UI: `/settings`. **Не в БД** — `localStorage` ключ `pah_settings_{userId}`.

![[assets/ui-settings.png]]

## Секции UI
- Профиль (имя, email — из Auth)
- Финансы: валюта, начало фин. месяца, учёт остатков, виджеты Dashboard
- Задачи / Привычки / Уведомления (аккордеоны)
- Привязка [[Telegram]]

## Тема и soft-карточки

```typescript
// frontend/src/theme.ts
export function createAppTheme(mode: PaletteMode) {
  return createTheme({
    typography: { fontFamily: '"Plus Jakarta Sans", "Segoe UI", sans-serif' },
    shape: { borderRadius: 20 },
    palette: {
      background: isDark
        ? { default: '#12141A', paper: '#1C1F28' }
        : { default: '#EEF0F4', paper: '#FFFFFF' },
      secondary: { main: '#6366F1' },
      // ...
    },
  });
}
```

```tsx
// frontend/src/components/SoftCard.tsx
<Box sx={{
  bgcolor: 'background.paper',
  borderRadius: 3,
  boxShadow: (theme) =>
    theme.palette.mode === 'dark' ? softShadowDark : softShadowLight,
  p: padding,
}} />
```
