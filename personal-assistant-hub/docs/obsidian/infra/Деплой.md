# Деплой

Источник: `deploy/README.md`.

## Prod-стек
- Compose: `docker-compose.yml` + `deploy/docker-compose.prod.yml`
- Порты DB/Redis/сервисов закрыты с хоста
- Caddy (в compose) — TLS: `$DOMAIN` → frontend, `$API_DOMAIN` → gateway
- Frontend: `Dockerfile.prebuilt`
- Путь на сервере: обычно `/opt/personal-assistant-hub`

## Первый запуск

```bash
git clone …
cd PersonalAssistantHub/personal-assistant-hub
cp deploy/env.production .env
# отредактировать секреты
./deploy/deploy.sh
```

DNS: домен сайта + `api.<домен>` → IP. Порты 80/443.

## Автозапуск
- `restart: always` у контейнеров
- systemd: `personal-assistant-hub.service` после Docker
- helpers: `check_*.py`, `fix_autostart.py`, …

```bash
systemctl enable personal-assistant-hub.service
systemctl enable docker
```
