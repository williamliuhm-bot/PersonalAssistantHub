# Конфигурация

Файлы: `.env.example` (dev), `deploy/env.production` (prod). **Секреты в git не коммитить.**

## Ключевые переменные

| Переменная | Смысл |
|------------|--------|
| `JWT_SECRET_KEY` / `JWT_ALGORITHM` | Общая подпись JWT |
| `ADMIN_EMAIL` | Bootstrap admin |
| `POSTGRES_PASSWORD` | Пароль БД (prod) |
| `DOMAIN` / `API_DOMAIN` | Хосты для Caddy |
| `VITE_API_URL` | База API при сборке фронта |
| `API_PUBLIC_URL` | Публичный gateway (webhook Telegram) |
| `RATE_*_RUB` / `VITE_RATE_*` | Курсы для UI |
| `SMTP_*` | Email-уведомления |
| `TELEGRAM_BOT_TOKEN` | Токен бота |
| `TELEGRAM_BOT_USERNAME` | Username бота |
| `TELEGRAM_WEBHOOK_SECRET` | Секрет webhook |
| `TELEGRAM_DEFAULT_CHAT_ID` | Fallback chat |
| `TELEGRAM_USE_POLLING` | Dev без webhook |
| `TELEGRAM_PROXY_URL` | Прокси к Bot API |
| `TELEGRAM_WEBAPP_URL` | HTTPS origin Mini App (`…/tg`) |
| `INTERNAL_SERVICE_TOKEN` | Finance ↔ Notification |

Compose также задаёт URL сервисов и номера Redis DB.
